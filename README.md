# Caesar Cipher

A Caesar cipher implementation in both Java and Python.

## What is a Caesar Cipher?
A simple encryption technique where each letter in the text is shifted by a fixed number of positions in the alphabet. For example with shift 3: A → D, B → E, C → F.

## Files
- `cesar.java` — Java implementation
- `cesar.py` — Python implementation

## Usage

**Python:**
```bash
python cesar.py
```

**Java:**
```bash
javac cesar.java
java cesar
```

## Example
```
Input shift: 3
Input message: hello world
Original  | hello world
Encoded   | khoor zruog
Decoded   | hello world
```
